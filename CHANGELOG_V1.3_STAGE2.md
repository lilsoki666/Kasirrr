# Kasir Kita V1.3 Stage 2

## Smart Navigation
- Added safe horizontal swipe navigation between the six top-level screens.
- Swipe left moves to the next toolbar page.
- Swipe right moves to the previous toolbar page.
- Vertical scrolling remains unchanged because a swipe is only accepted when horizontal movement is dominant.
- Active toolbar item is highlighted automatically when the screen changes.
- No new third-party dependency was added.
- Existing database, transaction, inventory, reports, and printer systems are preserved.
